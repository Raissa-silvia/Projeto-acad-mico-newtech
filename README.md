### 📖 Sobre o projeto

Sistema de quiz interativo desenvolvido como o **primeiro Projeto Integrador Multidisciplinar (PIM)** do curso de Análise e Desenvolvimento de Sistemas, em grupo.

O projeto simula um **aplicativo gamificado** voltado ao incentivo e ao engajamento no aprendizado de tecnologia. Ele foi proposto como solução digital para a **NewTech**, uma empresa fictícia criada para o desafio acadêmico.

### 🎯 Problema e solução

| | |
|---|---|
| **Desafio** | Manter as pessoas motivadas e engajadas ao aprender tecnologia |
| **Solução** | Um quiz com níveis de dificuldade, que transforma o estudo em uma experiência de jogo |

### ✨ Funcionalidades

- ✅ **3 níveis de dificuldade:** iniciante, intermediário e avançado
- ✅ **Banco de perguntas em JSON**, separado por nível, o que facilita adicionar ou editar perguntas sem mexer no código
- ✅ **Registro de resultados** por nível, salvos em arquivos JSON

### 🗂️ Estrutura do projeto

| Arquivo | Função |
|---|---|
| `quest.py` | Código principal do quiz |
| `perguntas_iniciante.json` | Perguntas do nível iniciante |
| `perguntas_intermediario.json` | Perguntas do nível intermediário |
| `perguntas_avancado.json` | Perguntas do nível avançado |
| `resultados_iniciante.json` | Resultados do nível iniciante |
| `resultados_intermediario.json` | Resultados do nível intermediário |
| `resultados_avancado.json` | Resultados do nível avançado |

A separação entre **código** (`quest.py`) e **dados** (arquivos JSON) deixa o sistema organizado e fácil de manter.
